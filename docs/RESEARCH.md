# Portfolio research and current-site review

Reviewed 8 November 2026. This is a curated set relevant to a senior engineering hiring audience, not an objective ranking or exhaustive survey.

## Existing portfolio

Source: https://www.ajaykc.com/ (rendered browser content and web extraction).

Observed strengths: specific platform expertise, named Australian Government projects, role history, résumé link, direct professional contact routes. These are the substantive foundation of the redesign.

Design observations: dark bordered panels repeat throughout; the introduction restates similar positioning in the profile, hero and about; technology imagery receives attention that could go to project evidence. The project section contains descriptions but limited visual or technical depth. These are design judgments from the inspected page, not usability-test findings.

Recommendation: simplify the opening to one clear positioning statement; move three substantive projects ahead of the biography; make individual contributions explicit; use restrained visual hierarchy to support fast hiring decisions. Keep accessibility a visible property of the portfolio itself.

## Synthesis

Use an original architectural editorial composition, not a mashup of recognisable templates. The portfolio should communicate care, structure and delivery. Large project features are an intentional departure from the text-heavy reference sites because Ajay has named public-platform work worth making visible.

Recruiter pathway: role/location → selected work → personal contribution → capabilities/experience → résumé/contact. A visitor should not need to complete an animation or navigate a 3D scene to follow this path.

## Evidence boundaries

No user research, conversion data or quantified performance audit was conducted. Statements about likely recruiter needs are design assumptions informed by the user-selected audience. Recheck reference sites if revisiting this research after substantial time because these portfolios change.
